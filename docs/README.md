# راهنمای مستندات پروژه

تاریخ تدوین: 2026-10-12 — بازبینی: 2026-10-13 — نسخه طراحی: 0.2 — وضعیت: **معماری نهایی و آغاز فاز ۱ صریحاً تأیید شده‌اند؛ زیرساخت فاز ۱ نصب و تست‌های backend موفق‌اند؛ مرور بصری و تأیید کاربر باقی است**.

مستندات طراحی فاز صفر حفظ شده‌اند و کد زیرساخت/هویت فاز ۱ اضافه شده است. migration هویت روی SQLite تازه اجرا شده و ۳۷ تست Pest موفق‌اند؛ بررسی مرورگر/صفحه‌کلید در محیط کاربر باقی است. داده مالی واقعی و موتور محاسبات مالی/شرعی نداریم. «بررسی منبع» در این مستندات به معنی مشاهده منبع رسمی است؛ به معنی تأیید انطباق یک الگوریتم با تمام فروض شرعی نیست.

## نتیجه بازبینی 0.2

آغاز ثبت و افتتاحیه ۲۰ مرداد ۱۴۰۵، پایان اولین دوره ۲۰ مرداد ۱۴۰۶ و تسویه اعلام‌شده خمس ۱۴۰۵ در تصمیم‌های قطعی ثبت شدند؛ ساعت مرز و تأیید قلم‌به‌قلم سرمایه مخمّس همچنان مستقل‌اند. [راه‌انداز و افتتاحیه](OPENING_BALANCE.md) مرجع جریان اولیه، داده‌های لازم و مرز قطعیت است. [بازبینی معماری](ARCHITECTURE.md) کاهش ساختارهای اضافی و تفکیک فازها را توضیح می‌دهد.

تمام مستندات نسخه 0.1 خوانده و با درخواست جدید تطبیق داده شدند. قراردادهای مالی و منابع قبلی حفظ شده‌اند؛ پیشنهادهای تخصصی با تأیید اولیه معماری، خودکار مصوب نشده‌اند. گزارش این تحویل و اعتبارسنجی واقعی در [PROGRESS](PROGRESS.md) است.
