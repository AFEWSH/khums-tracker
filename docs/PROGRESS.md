## وضعیت فعلی — 2026-10-12

**فاز ۰: مستندات تحلیل و طراحی تهیه و بازبینی شده؛ منتظر تأیید کاربر.** هیچ قابلیت اصلی، scaffold، migration یا package ساخته/نصب نشده است. فاز ۱ مجوز شروع ندارد.

## انجام‌شده

- بررسی workspace: کد برنامه یا docs قبلی وجود نداشت؛ `.idea/` از قبل موجود بود و تغییر داده نشد.
- بررسی محیط قابل مشاهده: PHP CLI 8.4.26، Composer 2.9.5 و Node.js v22.22.3 موجودند؛ سازگاری کامل extensionها و packageها هنوز آزموده نشده است.
- تحلیل دامنه و معیارهای پذیرش R01–R20؛ تهیه معماری Laravel یکپارچه، مدل داده و روابط، تراکنش و کنترل همزمانی.
- طراحی دفترکل/مقدار/lot/منشأ، دقت ریالی، سیاست پیشنهادی FIFO، اصلاح گذشته و قیمت تاریخی.
- طراحی گزارش اقتصادی مبتنی بر CPI و مرز جریان‌های خارجی، با مثال‌های عددی مستقل.
- بررسی صفحات رسمی احکام و ثبت شماره‌های مشاهده‌شده، لینک، نوع حکم و وضعیت اعتبارسنجی؛ موارد ناقص جدا مانده‌اند.
- طراحی موتور خمس/زکات، snapshot، بستن و اصلاح سال، تفکیک تسویه، دوره قمری و مرز تصمیم کاربر.
- تهیه UX، نقشه راه، ریسک‌ها، برنامه تست و دستورهای AGENTS.
- پرسش از کاربر درباره مرز سال، روش افتتاحیه و سیاست/واقعیت منشأ مخلوط؛ پاسخی هنوز دریافت نشده است.

## اعتبارسنجی این تحویل

- بررسی اسناد با اسکریپت موقت Python: وجود تمام اسناد درخواستی، مقصد پیوندهای داخلی، توازن بلوک‌های کد و whitespace بررسی شد؛ موفق.
- محاسبه مستقل نمونه‌های خرید/فروش و پنج سناریوی CPI با `fractions.Fraction` و آزمون ثابت‌بودن نتیجه با تغییر مقیاس شاخص انجام شد؛ موفق. این بررسی مثال طراحی است، نه تست موتور برنامه.
- فهرست منابع: ۲۹ شناسه یکتای منبع رسمی ثبت شد؛ شماره‌های ثبت‌شده مشاهده‌شده‌اند و موارد partial/pending صریح‌اند.
- بازبینی سازگاری طراحی: اصلاح backdated باید هم تخصیص lot و هم اسناد تعدیل بهای فروش را هماهنگ کند؛ بهای افتتاحیه بدون تاریخچه با بهای تاریخی تفکیک شد.
- آزمون Laravel/Pest/Feature/Integration: **اجرا نشده و در این فاز قابل اجرا نیست**؛ برنامه و تست محصول هنوز وجود ندارند.
- داده CPI واقعی وارد نشده؛ منبع مشخص سری داده هنوز تأیید نشده است.
- قواعد شرعی: مشاهده منابع به معنی تکمیل همه فروض یا تأیید الگوریتم نیست؛ هیچ rule فعال نداریم.
