# بایگانی متن احکام

متن رسمی لازم برای قواعد خمس. منبع: پایگاه رسمی دفتر آیت‌الله سید علی حسینی سیستانی، `sistani.org/persian/`. تاریخ مشاهده: 2026-10-31.

- `khums/` کل فصل خمس از «توضیح المسائل جامع جلد ۲، چاپ ۱۴۰۳»: یک فایل برای هر صفحهٔ رسمی با لینک، تاریخ مشاهده، hash، متن و پاورقی‌ها.
- `qa/` پرسش‌وپاسخ سایت رسمی در یازده دسته. **این بخش متن رساله نیست** و تاریخ انتشار هر پاسخ در منبع نیامده است.
- `index.json` فهرست صفحات، مسائل و hashها.

**وضعیت Git:** تا خصوصی شدن مخزن، `khums/` و `qa/` در `.gitignore` هستند (A82). `index.json` برای راستی‌آزمایی همان متن کافی است. نسخهٔ خام HTML در `storage/app/private/rulings-raw/` نگهداری می‌شود.

**hash:** مقدار `sha256` صفحه، SHA-256 متن پس از front matter است. `sha256` هر مسئله به متن همان مسئله برمی‌گردد.

**نوع حکم:** فیلدهای `wording` و `wording_with_footnotes` فقط وجود عبارت‌های «احتیاط واجب»، «احتیاط لازم» و «احتیاط مستحب» را نشان می‌دهند و با جست‌وجوی متن ساخته شده‌اند. «بدون عبارت احتیاط» یعنی این عبارت‌ها نیامده، نه اینکه تمام مسئله فتوا است. یک مسئله ممکن است چند نوع حکم داشته باشد؛ در هر قاعده باید متن خوانده شود.

این بایگانی فتوا را تفسیر یا قاعده‌ای را فعال نمی‌کند. برداشت‌ها در [KHUMS_RULES](../KHUMS_RULES.md) هستند و تا بازبینی معتبر نیستند.
