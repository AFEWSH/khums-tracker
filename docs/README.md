# راهنمای مستندات پروژه

## وضعیت

مرجع ترتیب کار و وضعیت فازها [PLAN](status/PLAN.md) است (P0 تا P9، تصمیم‌های D31–D33). دامنهٔ محصول محاسبه و پیگیری خمس است (D29/D30): زکات، CPI/عملکرد اقتصادی، گزارش‌ها و خروجی عمومی، XLSX و سازگاری MySQL معوق‌اند و کد موجودشان حذف نمی‌شود. نتیجهٔ آزمون‌ها و سابقهٔ تحویل‌ها در [PROGRESS](status/PROGRESS.md) است و قواعد شرعی واقعی همگی غیرفعال‌اند.

«بررسی منبع» در این مستندات به معنی مشاهدهٔ منبع رسمی است، نه تأیید انطباق یک الگوریتم با تمام فروض شرعی.

## مسیر مطالعه

ابتدا [PLAN](status/PLAN.md)، سپس [نیازمندی‌ها](product/PRD.md)، [تصمیم‌ها و پرسش‌های باز](status/DECISIONS.md) و [معماری](design/ARCHITECTURE.md) را بخوانید. تأیید معماری به‌تنهایی پاسخ فرضی به پرسش‌های شرعی یا تأیید همه فازهای آینده محسوب نمی‌شود.
