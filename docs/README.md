# راهنمای مستندات پروژه

تاریخ تدوین: 2026-10-12 — نسخه طراحی: 0.1 — وضعیت: **پیشنهادی، در انتظار تأیید کاربر**.

این خروجی فقط فاز تحلیل و طراحی است. برنامه، migration، داده واقعی، موتور محاسبه یا آزمون اجرایی هنوز ساخته نشده است. «بررسی منبع» در این مستندات به معنی مشاهده منبع رسمی است؛ به معنی تأیید انطباق یک الگوریتم با تمام فروض شرعی نیست.

## مسیر مطالعه و تأیید

ابتدا [نیازمندی‌ها](PRD.md)
[تصمیم‌ها و پرسش‌های باز](DECISIONS.md)
[معماری](ARCHITECTURE.md)
را بخوانید.
